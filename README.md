# IPL_SQL_Analysis
IPL Match Analysis using SQL 🏏

This project explores IPL T20 match dataset using SQL queries to uncover interesting insights.

## Dataset

- IPL Matches Data  
- Columns: id, season, city, date, match_type, player_of_match, venue, team1, team2, ...

## SQL Analysis

- Total matches per season
- Toss decision pattern (bat/field)
- Top Player of the Match awardees
- Team with most wins
- Super Over match stats

## Output Screenshots

Results are available in the `outputs/` folder.

## Tools

- MySQL Workbench
- Dataset source: Kaggle IPL dataset
